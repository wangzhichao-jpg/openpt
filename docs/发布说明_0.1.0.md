# 0.1.0 本地发布准备说明（尚未公开发布）

本地版本为 0.1.0，尚未执行推送、上传或公开发布；本文不代表业务批准或通过计划书 8.4 的全部正式发布门槛。软件不自动放行，结论须由授权人员签字。

## 新功能

- 平衡/不平衡均匀性 ANOVA、F 和 Ss；稳定性单样本、pooled 和 Welch 模型，记录实验单位及设计警告。
- GL002 算法 A/S、中位数与 NIQR、指定值及不确定度、D、D%、z、z′、ζ、En；报告复核和批量差异表。
- Excel/CSV 校验和来源定位、候选批次、种子抽样、三格式计算书、人工决定、运行快照、审计包校验和重现。
- 决定条目默认校验，自定义条目须显式允许；新增中文用户手册、R 对照及三路线依赖 ADR。

## 已验证范围与差异

R 4.3.3 的 base R `aov`/`anova`、`t.test` 和依据 GL002 独立编写的稳健及评分公式已用于公开和内部样例；详细数据、结果、相对误差与规则见 `validation/crosscheck_report.md`、`.json`。GL003 A.1/A.2、GL002 B1、PoC 的公开案例、公开合成工作簿及固定种子 200 组随机输入均有对照。公开示例评分使用相同已处理的指定值和不确定度，未独立验证完整定值预算；随机算法 S 的统一自由度 1 为数值试验，不代表实际实验设计。

严格相对误差下，固定负方差例有 2 项、随机 ANOVA 有 30 项理论零值差异：R 的线性模型产生极小浮点残差，相对零的误差为 1。全部观测完全相同时，openpt 标记 F 不可判定，R `aov` 可能因舍入给出有限 F 并警告近乎完美拟合不可靠；不得将其误当成可判定结果。差异原样保留，不用绝对容差掩盖。

同一随机 CSV 的三路线比较中，pt13528 有 3478 项通过、1722 项接口未覆盖、400 项 type 6 仅报告；公开 B1 和示例比较有 76 项通过、12 项未覆盖、12 项仅报告。其他三路线结果和方法口径见 `validation/threeway_report.md`、`threeway_examples_report.md`、`threeway_random_report.md` 和 ADR-004。pt13528 与 openpt 共用 SciPy；metRology 0.9-29-2（GPL >= 2）默认停止规则不同，其结果单独报告，不判成同规则通过。各对照均不能证明实际实验独立性或统计设计适用性。

## 残余风险与未覆盖设计

- 0.1.0 准备时标准扩展公式及条款号尚未核对；后续已对 GB/T 28043-2019 的部分条款进行图像核对，范围和未完成项见当前文档。不平衡 ANOVA、Welch、σ′、公议值不确定度等扩展方法须经统计负责人批准。
- 0.1.0 发布准备时尚未进行原生 Windows 实机测试、用户试点、专家签字及实际平台 CI；Wine 不等同原生 Windows，矩阵配置不等于矩阵已运行。
- 0.1.0 的配对或相关设计、复杂相关不确定度、定性微生物、多参数综合及 GB/T 28043 扩展不在受支持范围。程序不能识别未声明的相关性、伪重复或不确定度重复计入；临界容差和停止规则可影响边界结果。
- 审计清单无数字签名或外部可信根，不能识别内容和清单同时被替换；应独立保存可信摘要或使用外部签名。第三方许可证和公开数据授权须在公开前人工复核。
- 维护者联系方式、GitHub/Gitee 账号、PyPI 名称确认和私密漏洞报告渠道仍待用户提供；其他正式发布条件见 `docs/发布清单.md`。
