# ADR-003：抽样及审计包的阶段性约定

状态：施工中；运行快照与重现规则尚未实现，本文件不代表完整方案已经通过验收。

- 抽样使用 `numpy.random.Generator(PCG64)`，逐层无放回抽取；以比例份额为目标，每层至少一个，调整时选择与目标份额偏差最大的可调整层，同分按分层输入顺序。记录总体、完整分层、各层数量、种子和 NumPy 版本。
- 盲码是对 1 至抽样数随机置换后加固定前缀，检测顺序对每个抽中单元的两次重复再次随机置换。盲码不是加密；持有种子、映射表或程序的人可以恢复关联，不能作为身份保密保障。人工须确保两次重复分别独立取样。
- 阶段性审计清单使用 SHA-256，`manifest.json` 的 `files` 对象映射相对文件名至小写哈希，清单不自哈希。ZIP 校验不执行和解压内容；拒绝路径穿越、符号链接、重复成员、遗漏和未列入清单的文件。没有签名或外部可信摘要时不能验证清单真实性。
- 已有独立的递归 JSON 比较函数：有限浮点采用相对容差 1e-12、绝对容差为零；整数之间精确比较，布尔值和数值区分，非有限数判为差异。函数当前不排除任何字段。
- 本批尚未实现自动创建的运行目录、重现命令及易变字段排除清单。完整格式和排除规则尚待设计和测试，不应将当前实验性审计包作为完整的可重现记录。
