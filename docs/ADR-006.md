# ADR-006：多被测量输入与隔离计算

## 状态

内测试用；测量设计和单位须由人员审查。

## 决策

“均匀性”“稳定性”“报告声称值”可添加可选列“被测量”。未填写任何被测量时保持原单量行为；填写后按该列分别读取、计算和复核。多个被测量时，含数据的三张表必须逐行明确被测量，不得把无标签数据自动分配到多个量。数据名称须为非空文字；相同名称在各表对应同一量。

新增选填“被测量配置”表，列为“被测量、字段、值”，每行配置一个参数。允许按量设置 `单位`、`sigma`、`sigma_pt`、`delta_e` 及所列方法参数；未设置时继承公共项目信息及方法配置，重复键、未知字段和未知被测量拒绝。不同量的单位应分别登记。`sigma` 与 `sigma_pt` 的沿用规则见 ADR-005。

使用内存中的临时视图屏蔽其他量，保留原行号和原值单元格地址；原始工作簿快照不变。各量计算结果嵌套在 `被测量` 下，复核 CSV 和批量总表标明量名，计算书按量分章。配置虚拟位置映射回原“被测量配置”单元格。

参加者结果表目前没有被测量列；多量工作簿若填写参加者结果，程序拒绝混算，须分别运行。共享指定值或不确定度的适用性仍由人员审查，不推断相关性。
