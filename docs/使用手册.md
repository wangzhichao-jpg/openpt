# OpenPT 操作手册（试用版）

本软件尚未满足正式发布验收条件，计算结果必须经具备资质的人员复核。**软件不自动放行，结论须由授权人员签字。**

## 安装

需要 Python 3.10、3.12 或 3.13。当前尚未发布 PyPI 版本，应在公开仓库源码根目录执行以下安装命令；清华源仅用于解析依赖，不代表软件包已发布。

Linux：

```sh
python -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple .
```

Windows PowerShell：

```powershell
py -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple .
```

若命令不在 PATH，将下述命令中的程序名替换为 Linux 的 `python -m openpt` 或 Windows 的 `py -m openpt`。Windows 原生系统尚未实测。

## 六步工作流

以下示例从源码根目录在 Linux shell 执行，使用仓库中完全合成的 `examples/GL003_A1.xlsx` 作为填好的 `input.xlsx`；实际项目中请填写自己生成的模板。输出目录必须不存在，避免覆盖。Windows 用户可通过 PowerShell 将 `$RUN` 换成实际运行目录路径。

### 1 抽样

```sh
openpt sample --units 100 --pick 20 --seed 42 --output sample-output
```

记录总体、分层、种子、算法和检测次序。`sample-output/sample.json` 含盲码映射及种子，不能直接交给盲测人员。抽样不足 10 个只给出警告；每次重复独立取样须人员保证。

### 2 生成并填写模板

```sh
openpt template blank.xlsx
```

把真实数据填入模板并另存为 `input.xlsx`；本示例可以复制合成工作簿：

```sh
cp examples/GL003_A1.xlsx input.xlsx
```

### 3 只读检查

```sh
openpt validate input.xlsx
```

返回 0 为检查未发现问题，1 为发现问题，2 为输入错误。此检查只覆盖测量表，不能代替统计设计审查；公式即使有缓存也不能用于计算。

### 4 运行计算

```sh
openpt run input.xlsx --runs-dir runs --sample-record sample-output/sample.json
```

屏幕显示新运行目录名；将它赋给变量（下面适用于当前目录仅有一次运行的演示）：

```sh
RUN="$(find runs -mindepth 1 -maxdepth 1 -type d -print -quit)"
```

### 5 复核并记录人工决定

在“报告声称值”表登记声称量、来源和报告模型后，使用以下命令。批量复核接受多个工作簿：

```sh
openpt review input.xlsx --runs-dir review-runs
openpt review-batch input.xlsx --output differences.xlsx
openpt decide "$RUN" --item 均匀性 --decision 接受 --by 复核人 --note 演示
```

`--item` 必须是结果中的顶层条目，拼写不匹配时列出可用项；确须登记结果之外的事项，显式加 `--allow-new-item`，审计记录会标为自定义。决定追加生成新版本计算书，不改变原始结果；发生中断后先检查清单。

### 6 打包归档与重现

```sh
openpt pack "$RUN" -o audit.zip
openpt verify audit.zip
openpt reproduce "$RUN"
```

运行目录含输入原始字节及其 SHA-256、配置、环境、结果、计算书、日志和清单。`verify` 核对包内哈希而不解压执行；`reproduce` 先核验再重算。清单没有数字签名，攻击者同时更换内容和清单时无法验证真实性；应从可信渠道独立保存包摘要或采用外部签名。

## 工作表填写

- **填写说明**：阅读提示，不作为数据。
- **项目信息**：项目名称及统一单位必填。
- **方法配置**：登记 alpha、σ 来源及临时/最终阶段、均匀性严格配置、稳定性方法及独立层级；研究模型不得冒充实际独立性。`sigma` 是均匀性和稳定性判据标准差，`sigma_pt` 是 z 等评价统计量的分母；只填一个时自动沿用，两个都填时各自使用。指定值表中临时值、最终值及确定程序仍需单独登记。见 ADR-005。算法 A 的 `gbt28043` 停止规则分别按均值和尺度各自三位有效数字比较（十进制半偶舍入），与默认 `gl002` 不同；它须单独选择，选择均匀性/稳定性模式不会自动切换。选定算法 A/S 停止规则。
- **GB/T 判据依据**：同一被测量可输入 `sigma` 或 `delta_e`；两者均输入时必须用 `gbt_criterion_basis` 选择 `sigma_pt` 或 `delta_e`。单独输入时自动选择相应依据。基本均匀性与稳定性阈值分别按所选依据使用 0.3σ_pt 或 0.1δ_E；指定值不确定度也按所选依据提示。δ_E 模式不将该阈值代入标准中以 σ_pt 表达的扩展判据，选扩展主判据时显示未评价；方法重复性检查仍需要 σ_pt。`delta_e` 与被测量须使用相同单位。
- **均匀性**：每个包装单元每次重复一行，填写单元编号、重复编号、值和单位；常规设计每单元至少两次，不能重复测量时应显式选择 `replicate_type=single`。GL003 主判据用 `gl003_hom_criterion` 预选 `f_test`（默认，4.2）、`ss_0.3sigma`（4.3）或 `both`（两者均需通过）；旧的 `strict_homogeneity=TRUE` 等同 `both`。可用 `report_gl003_hom_criterion` 登记报告所用判据，口径不同会提示 `MODEL_SWITCH`。
- **GB/T 稳定性单测**：任一稳定性组每单元仅一次测量时，仍可计算 B.5 基本均值差判据，但该时间组的组内重复性不可评价；不将缺失的重复性视为通过，实验设计和方法适用性仍须审核。
- **稳定性**：时间组填写“基线”和“稳定期”，其余列同上；样本独立性、取样次数和试验顺序由人员核实。
- **长表和宽表**：也可在“均匀性”或“稳定性”正式表中使用宽表，列为单元编号、`测定1`、`测定2`……和单位；稳定性另含时间组。默认按表头自动识别，方法配置中的 `layout` 可设为 `long` 或 `wide`。生成模板内的“示例-”工作表仅供参考，不参与计算；请复制表头到正式表。空测定单元格会报告缺失，问题和来源定位到原单元格。
- **多个被测量**：在均匀性、稳定性及报告声称值的“被测量”列填写名称；多量工作簿中有数据的各行都须归属到某一被测量。可在“被测量配置”中按“被测量、字段、值”分别登记 `单位`、`sigma`、`sigma_pt`、方法等，未填写的字段继承公共配置。各量独立计算与复核，CSV 和计算书按量标识。当前参加者结果不能在多量工作簿中分组，请分开运行；完整规则见 ADR-006。
- **参加者结果**：每人一行，填写编号、值、单位；ζ、En 需要相应 u(x)、U(x)、k，且须确认与指定值不相关。
- **报告声称值**：登记统计量、数值、显示小数位、来源；按需选择报告模型和时间组。报告模型复现与推荐模型分别显示。
- **指定值与不确定度**：登记方法、来源、值、不确定度、σ 确定程序和分量映射；谨防重复计入。扩展公式的适用性须事先批准。GB/T 模式下，如已有时点主判据未通过或未评价，`stability_disposition=pending` 将暂停参与者评价；`budgeted` 须有书面依据并将储存/运输影响映射至预算，`reviewed` 须有书面依据，`withhold` 始终暂停。软件不从均值差推算不确定度，不验证审批或未声明的相关性。
- **算法S**：至少两个同类标准差或极差，各行使用同一自由度 1～10。
- **候选批次**：记录编号、物品、量值、材质、来源、日期、状态等；失败或弃用须填写理由，关联批次须存在。

## 读计算书与状态

先核对输入来源和方法，再查看原始全精度、中间量、F/t、自由度、p、Ss 和用途阈值；显著性结论与用途结论独立。临界值比较采用相对容差 `1e-12`，靠近边界须人工复核。

| 状态 | 含义 |
|---|---|
| OK | 该项计算可用，不代表放行 |
| NOT_EVALUATED / UNASSESSED | 条件不足或未评价 |
| INDETERMINATE | 数值退化，不能判定 |
| DESIGN_WARNING | 设计需留意，不等于自动否决 |
| DESIGN_REVIEW | 设计或前提需审核，不能直接评价 |
| PROVISIONAL | 采用临时数据 |
| NOT_CONVERGED / REFERENCE_NOT_CONVERGED | 迭代或收敛对照未收敛 |
| STOP_RULE_SENSITIVITY | 停止规则影响显示值 |
| MATCH / NOTE / DIFFERENCE | 分别为复核一致、提示、待核差异 |

导入检查问题码：`MISSING` 缺失、`DUPLICATE` 编号重复、`NON_NUMERIC` 非数值、
`UNIT_MISMATCH` 单位不一致、`FORMULA` 公式、`FORMULA_NO_CACHE` 公式缺缓存值。
即使公式有缓存，计算入口仍拒绝公式。

复核差异类型用于解释状态：`CRITERION_EXCEEDED` 用途阈值超限；`MODEL_SWITCH`
模型切换；`NOT_REPRODUCIBLE` 不能按报告模型复现；`PSEUDO_REPLICATION` 技术重复
可能被当作独立观测；`REPORT_RULE_UNKNOWN` 报告规则未知；`REVIEW_NOTE` 一般提示；
`REVIEW_REQUIRED` 需要复核；`ROUNDING_INTERMEDIATE` 中间修约差异；`SIGMA_COMPOSITE`
合成标准差；`VALUE_MISMATCH` 数值不一致。上述类型及 `DESIGN_REVIEW`、
`DESIGN_WARNING`、`STOP_RULE_SENSITIVITY` 均需结合说明和来源人工核实。

## 常见问题

- 单位不一致、重复编号、单元测量不足：按错误所列工作表及位置回到原始记录核对，勿自动改值。
- CSV 解码错误：按真实编码使用 `--encoding gbk` 等；CSV 仅导入一种测量表，运行时需提供单位。
- F 不可判定、尺度为零：检查分辨力和记录精度，不等于绝对均匀。
- 审计清单不一致：停止操作，从可信备份恢复并调查，不要简单重建清单掩盖问题。
- 复核结果差异：先核对模型、实验单位及显示修约，不能仅据差异断言原报告错误。

## 方法与条款

| 方法 | 依据与边界 |
|---|---|
| 均匀性 F、Ss | CNAS-GL003:2018 4.2、4.3；不平衡 ANOVA 为扩展方法，需批准 |
| 稳定性 t、均值差 | GL003 5.2.1、5.2.2、5.3；Welch 为扩展方法 |
| 算法 A、S、中位数与 NIQR | CNAS-GL002:2018 附录 A.2、A.3、A.4；分位数 type 7，见 ADR-002 |
| 指定值、z、z′、ζ、En | GL002 4.3、4.4；GB/T 28043-2019 7.7.3 式(6)、9.2.1 式(10)、9.3～9.7；评分边界按所选 GL002 模式，适用性须审核 |
| 均匀性、稳定性实验标准模式 | GB/T 28043-2019 B.2、B.3、B.5、B.6；实验设计与标准适用性须审核 |

## 不能做什么

不能自动选择批次、删除异常值、自动签字或放行；不能证明实验独立或识别未声明的相关性和不确定度重复计入。不适用于配对/相关设计、未批准的扩展模型、定性微生物及多参数综合评价。未完成原生 Windows 实测、用户试点及专家签字；请勿作为正式评价或认可判断的唯一依据。

### 报告模型

| 取值 | 含义和适用场景 |
|---|---|
| `recommended` | 按当前推荐模型重算；默认选择。 |
| `repeats_pooled` | 把重复值合并并采用合并方差，仅用于复现报告，须核查伪重复。 |
| `repeats_welch` | 把重复值合并并采用非齐方差模型，仅用于复现报告。 |
| `displayed_summary` | 对 t 使用报告中显示的均值、标准差和样本数，核查中间修约。 |
| `absolute` | 对算法 A 使用绝对容差候选停止规则，须核实报告规则。 |
| `gbt28043` | 按 GB/T 模式复现限值或算法 A 停止规则；须确认具体统计量适用。 |
| `gl003` | 按 GL003 模式复现均匀性或稳定性统计量与限值。 |

带 `:编号` 的统计量须填写实际参加者编号；均值、均值差和阈值可以填写时间组。
`assigned_method` 对应“指定值与不确定度”表的 `method`；`stability_period_options.kind` 在逐时点 JSON 中填写。
布尔值采用 TRUE/FALSE，模板中的“启用/关闭”会转换为布尔值。σ 来源等自由文本不是固定枚举。
