# 能力验证样品评价与定值工具 使用手册

## 开始使用

解压 Windows 包，双击 `能力验证样品评价与定值工具.exe`。无需安装 Python 或其他运行环境，也无需管理员权限。

点击“载入甲醛示例”，再点击“开始计算”。也可点击“选择数据文件”，选择 `能力验证样品评价与定值工具.exe` 同目录“示例案例”中的工作簿；文件夹提供甲醛、材料抗拉强度、颗粒振实密度和数字多用表四个案例，详见“案例说明.txt”。窗口显示均匀性、稳定性和指定值与标准不确定度；传递样显示各校准点的变差和限值。点击“打开计算书”查看完整计算过程，或点击“打开结果目录”查看全部文件。每次计算新建目录，结果位于个人文档的 `OpenPT结果` 文件夹。

在“方法配置”中添加或填写 `display_value_decimals`（0 至 12 的整数），可设置窗口和计算书中指定值、标准不确定度、能力评定标准差及参加者结果值的小数位，也控制计算书中的均值、样品间标准差和用途判据限值；留空使用 `display_sig_digits` 有效数字（默认 4 位）。旧参数 `display_mean_decimals`、`display_ss_decimals` 已废弃并忽略，填写时会提示改用上述设置。统计量仍由 `display_z_decimals` 控制。修约仅影响显示，不改变结果文件中的计算数值。

## 使用自己的数据

点击“新建数据模板”，选择保存位置；在 Excel 中填写并保存后，在程序中点击“选择数据文件”，然后点击“开始计算”。也可以直接选择符合模板格式的已有 Excel 工作簿。

工作簿“项目信息”填写项目名称和单位；“均匀性”按单元和重复填写测量值；“稳定性”按时间组、单元和重复填写测量值；“参加者结果”填写参加者编号和测量值。工作簿“方法配置”和“指定值与不确定度”决定计算方式和参数。可以先打开甲醛示例查看填写形式，修改模板以适应自己的数据。

### 参加者结果统计与多被测量

计算书“参加者结果统计量”按 CNAS-GL002:2018 附录 B 表 B1 列出结果数、中位值、NIQR、稳健 CV、最小值、最大值和极差；算术平均值和样本标准差仅供参考，不剔除离群值。多被测量工作簿须在参加者结果表“被测量”列逐行填写名称，各量分开计算；共享指定值和不确定度的适用性须人工审核。

计算成功后，若来源文字与随包示例原文相同而项目、定值方法或参加者数据已变，或来源文字可能与定值方法矛盾，程序会指明字段及单元格并提示核实；这些提示不阻止计算，也不能替代人工审查。

### 用参加者 NIQR 确定 σ_pt

1. 在“参加者结果”填写全部有效结果；包括离群值，程序不自动剔除。
2. 在“指定值与不确定度”选择定值 `method` 并填写其必需字段；将 `sigma_pt_method` 设为 `niqr`，清空 `sigma_final` 和 `sigma_temporary`。可填写 `sigma_pt_sig_digits` 指定最终 σ_pt 的有效数字；留空不修约。原有 `sigma_procedure` 文字会保留并附加自动说明。
3. 在“方法配置”明确填写 `quantile_method`：`linear` 是 type 7，对应 Excel `QUARTILE.INC` / `PERCENTILE.INC`；`weibull` 是 type 6，对应 `QUARTILE.EXC` / `PERCENTILE.EXC`；也可选 `hazen`（type 5）或 `median_unbiased`（type 8）。GB/T 28043 C.2.3 注3提醒不同算法可能给出不同结果。未选择 NIQR 作 σ_pt 时，留空默认 `linear`。
4. 如确需均匀性与稳定性判据采用该最终 σ_pt，在“方法配置”设 `criterion_sigma_source=sigma_pt` 并清空 `sigma`；否则不会自动回填。仅手工模式且选用此来源时，须填写最终 `sigma_final`。

自动来源还可选 `made`（MADe）、`algorithm_a`（s*）或 `algorithm_s`（w*）。选择算法 S 时，先在“算法S”表填写标准差和自由度，并在“方法配置”设 `algorithm_s_input_type=standard_deviation`；极差（`range`）不能直接作为标准差。`sigma_pt_method` 留空或 `manual` 沿用原手工模式。p<30 时 NIQR 和 MADe 有显著负偏倚（GB/T 28043 C.2.3 注2），应审核适用性。修约按 GB/T 8170-2008 一次四舍六入五成双，不得连续修约：0.01149 修约至两位有效数字为 0.011，不能先修约为 0.0115 再修约成 0.012。

### 分别设置稳定期与运输期的判据

推荐使用“稳定性时间组配置”表，而不是手写 JSON：
1. 在“稳定性”表填写稳定期、运输期的数据；在“稳定性时间组配置”表各填一行，时间组名称须完全一致。
2. GB/T 模式可在“判据规则（rule）”分别选择 `basic` 或 `extended`；需要时分别填写 `basis`、`delta_e` 和 `u2`。扩展判据还需要方法配置中的 `stability_u1` 和该组的 `u2`。
3. GL003 模式可为各组选择 `one_sample`、`two_sample` 或 `mean_difference`。混用方法且默认基线来源不同时，须明确选择 `baseline_source`：`homogeneity` 使用均匀性数据，`baseline_group` 使用稳定性基线组。趋势法只能全局设置。
4. 留空字段沿用全局设置或方法默认；表和 `stability_period_options` JSON 可以设置同一组的不同字段，但不能同时设置同一组的同一字段。

计算前保存并关闭 Excel 中的工作簿；程序读取输入并将计算结果写入新的运行目录，不覆盖原文件。

自 0.2.4 起提供 `GB-T合成检测.xlsx`：全部为合成数据，使用 GB/T 28043 模式、参加者公议及 `gbt_ss` 均匀性分量。0.2.3 安装包不含此示例。

## 常见问题：Windows 提示“智能应用控制已阻止可能不安全的应用”

Windows 11 的“智能应用控制”（Smart App Control）可能阻止本程序启动。本程序目前尚未进行代码签名，项目正在推进代码签名。对于无法判断信誉的应用，智能应用控制会放行具有有效签名的应用，阻止未签名的应用；该功能不能对单个应用放行，以管理员身份运行或尝试“仍要运行”类操作也不能绕过它。

在符合本单位安全规定的前提下，可以选择在“Windows 安全中心 → 应用和浏览器控制 → 智能应用控制设置”中关闭智能应用控制，或者换用未开启该功能的电脑。较新的 Windows 更新允许关闭后在安全中心重新开启；较早版本关闭后重新开启可能需要重置系统。请先确认本机的 Windows 版本和单位安全政策，再作决定。

请勿与 Microsoft Defender SmartScreen 的“Windows 已保护你的电脑”提示混淆：对于该提示，可以在确认文件来源可信并符合单位安全规定后，选择“更多信息 → 仍要运行”。此操作不能绕过智能应用控制。

## 常见配置错误与诊断提示

- 指定值表选择 `hom_source=gbt_ss` 时，方法配置的 `criterion_standard` 必须为 `gbt28043`，指定值表的 `hom_mapping` 必须选择 `assigned`、`sigma_prime` 或 `both`；不要保留 `none`。还须提供均匀性数据，且不得同时手工填写 `u_hom`。
- 选择指定值方法时，须填写 `source` 和 `uncertainty_source`，分别说明指定值及其不确定度的来源。
- 方法配置中的 `sigma` 用于均匀性及稳定性判据，`sigma_pt` 用于评价统计量；仅这两个方法配置字段只填一个时自动沿用。指定值表中的 `sigma_final` 或 `sigma_temporary` 是指定值建模使用的 σ_pt，**不会自动填入判据 sigma**。需要采用最终 σ_pt 时，可显式选择 `criterion_sigma_source=sigma_pt` 并清空 `sigma`；也可按原方式在方法配置中另行填写。
- 稳定性时间组未通过或未评价且 `stability_disposition=pending` 时，GB/T 模式会暂停参加者评价。先检查各时间组的数据和判据；确需处置时由授权人员依据实际情况选择 `budgeted`、`reviewed` 或 `withhold`，并登记依据，不能自动推定通过。
- 计算成功后的诊断提示见窗口结果区、结果 JSON 和计算书；计算出错时完整问题清单位于窗口结果区。
