# 能力验证样品评价与定值工具 使用手册

## 开始使用

解压 Windows 包，双击 `能力验证样品评价与定值工具.exe`。无需安装 Python 或其他运行环境，也无需管理员权限。

点击“载入甲醛示例”，再点击“开始计算”。也可点击“选择数据文件”，选择 `能力验证样品评价与定值工具.exe` 同目录“示例案例”中的工作簿；文件夹提供甲醛、材料抗拉强度、颗粒振实密度和数字多用表四个案例，详见“案例说明.txt”。窗口显示均匀性、稳定性和指定值与标准不确定度；传递样显示各校准点的变差和限值。点击“打开计算书”查看完整计算过程，或点击“打开结果目录”查看全部文件。每次计算新建目录，结果位于个人文档的 `OpenPT结果` 文件夹。

## 使用自己的数据

点击“新建数据模板”，选择保存位置；在 Excel 中填写并保存后，在程序中点击“选择数据文件”，然后点击“开始计算”。也可以直接选择符合模板格式的已有 Excel 工作簿。

工作簿“项目信息”填写项目名称和单位；“均匀性”按单元和重复填写测量值；“稳定性”按时间组、单元和重复填写测量值；“参加者结果”填写参加者编号和测量值。工作簿“方法配置”和“指定值与不确定度”决定计算方式和参数。可以先打开甲醛示例查看填写形式，修改模板以适应自己的数据。

计算前保存并关闭 Excel 中的工作簿；程序读取输入并将计算结果写入新的运行目录，不覆盖原文件。

当前开发源码另提供 `GB-T合成检测.xlsx`：全部为合成数据，使用 GB/T 28043 模式、参加者公议及 `gbt_ss` 均匀性分量。已发布的 0.2.3 安装包不含此示例。

## 常见配置错误与诊断提示

- 指定值表选择 `hom_source=gbt_ss` 时，方法配置的 `criterion_standard` 必须为 `gbt28043`，指定值表的 `hom_mapping` 必须选择 `assigned`、`sigma_prime` 或 `both`；不要保留 `none`。还须提供均匀性数据，且不得同时手工填写 `u_hom`。
- 选择指定值方法时，须填写 `source` 和 `uncertainty_source`，分别说明指定值及其不确定度的来源。
- 方法配置中的 `sigma` 用于均匀性及稳定性判据，`sigma_pt` 用于评价统计量；仅这两个方法配置字段只填一个时自动沿用。指定值表中的 `sigma_final` 或 `sigma_temporary` 是指定值建模使用的 σ_pt，**不会自动填入判据 sigma**。需要相同数值时请在方法配置中另行填写。
- 稳定性时间组未通过或未评价且 `stability_disposition=pending` 时，GB/T 模式会暂停参加者评价。先检查各时间组的数据和判据；确需处置时由授权人员依据实际情况选择 `budgeted`、`reviewed` 或 `withhold`，并登记依据，不能自动推定通过。
- 计算成功后的诊断提示见窗口结果区、结果 JSON 和计算书；计算出错时完整问题清单位于窗口结果区。
