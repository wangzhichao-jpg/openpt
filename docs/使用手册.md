# 能力验证样品评价与定值工具 使用手册

## 开始使用

解压 Windows 包，双击 `能力验证样品评价与定值工具.exe`。无需安装 Python 或其他运行环境，也无需管理员权限。

点击“载入甲醛示例”，再点击“开始计算”。也可点击“选择数据文件”，选择 `能力验证样品评价与定值工具.exe` 同目录“示例案例”中的工作簿；文件夹里的“案例说明.txt”介绍四个案例。窗口显示均匀性、稳定性和指定值与标准不确定度；传递样显示各校准点的变差和限值。点击“打开计算书”查看完整计算过程，或点击“打开结果目录”查看全部文件。每次计算新建目录，结果位于个人文档的 `OpenPT结果` 文件夹。

## 使用自己的数据

点击“新建数据模板”，选择保存位置；在 Excel 中填写并保存后，在程序中点击“选择数据文件”，然后点击“开始计算”。也可以直接选择符合模板格式的已有 Excel 工作簿。

工作簿“项目信息”填写项目名称和单位；“均匀性”按单元和重复填写测量值；“稳定性”按时间组、单元和重复填写测量值；“参加者结果”填写参加者编号和测量值。工作簿“方法配置”和“指定值与不确定度”决定计算方式和参数。可以先打开甲醛示例查看填写形式，修改模板以适应自己的数据。

计算前保存并关闭 Excel 中的工作簿；程序读取输入并将计算结果写入新的运行目录，不覆盖原文件。
