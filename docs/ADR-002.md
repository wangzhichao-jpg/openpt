# ADR-002：分位数及不平衡设计

状态：部分决定，待统计负责人审定。

## 临界值判定

采用软件附加的相对容差 `1e-12`（返工单 F1 方案 b）：比较两有限值 a、b 时，若 `|a-b| ≤ 1e-12 × max(|a|, |b|)`，按相等处理；绝对容差为零。仅影响判定，不修约或修改 JSON 中的原始浮点统计量。适用于能力统计量分档、F/t 与临界值、Ss 和稳定性均值差用途判据及 u(X) 提示。严格小于判据遇到相等按不通过处理；≤ 判据遇到相等按通过处理。真实差异若处于该容差内也会被当作边界，结果应人工复核；这不是十进制精确算术，也不能消除任意病态消差。迭代算法的收敛条件和输入有效性约束不使用此判据容差。计算书须披露该约定。


- GL002 附录 A.4 给出内插及 NIQR=0.7413×(Q3-Q1)，没有明确指定分位数算法。暂用线性插值 type 7，即排序数据零基位置 (n-1)p，保持与现有 NumPy 默认计算和已验表 B1 示例一致；其他实现可能产生不同值，须记录定义。
- 不平衡单因子随机效应扩展采用 n₀=(N-Σnᵢ²/N)/(g-1)，Ss²=max(0,(MSb-MSw)/n₀)。平衡设计退化为 GL003 4.3。扩展方法参考 Searle 等《Variance Components》(1992) 的单因子随机效应模型，具体页码未核对；不能冒称 GL003 给出该扩展。须审查独立、方差齐性等前提。
- u_hom/u_stab 分别登记 `none`、`assigned`、`sigma_prime` 或 `both`；假设分量相互独立，以平方和开方合成。`both` 或基础 u(X) 已含同一分量又被加入时输出 `DESIGN_REVIEW`，不评价。基础 u 已包含且不再分配时保留；程序依赖用户真实登记，无法发现未声明的重复计算。σ′ 扩展依据 ISO 13528 待核对条款号，模型须经批准。
- 已知值可输入已经评定的 u 或以互相独立的制备分量计算 √Σuᵢ²；专家公议可输入已评定的 X、u，或在独立同精度假设下输入专家结果，按 X=均值、u=s/√n 计算。这些是扩展方法，不能用于存在相关性、共同系统误差或不同精度且未获批准的情况；GL002 4.3.2 未为所有情形给出计算公式。
- 参加者公议值采用扩展方法 u(X)=1.25s*/√p，s* 为算法 A 的尺度或中位数法 NIQR；ISO 13528 待核对条款号。该式在中位数法及非正态分布下的适用性须经统计负责人批准；外部值不确定度由用户输入，不臆造。
- GL002 附录 A.3 算法 S 使用式 A.7—A.10 和表 A.1，支持共同自由度 1 至 10，记录每次迭代。超出表格或不同自由度的分组需采用经批准的其他方法。`gl002` 对“连续两次迭代后数值不再变化”的解释是：**至少完成两次更新，比较最近两次迭代结果在第三有效位是否相同**，不要求连续两次变化均为零；算法 A 与 S 采用相同解释，保持原算法 A 的停止结果。第三有效位比较使用十进制半偶舍入。另支持 `absolute`（绝对变化量不超过配置容差）；每次独立对照同时要求绝对变化量不超过 1e-12、相对变化量不超过 1e-12，最多至少迭代 10000 次，避免对小量级数据过早停止；两者三位有效数字不同时给出 `STOP_RULE_SENSITIVITY`，对照不收敛时提示 `REFERENCE_NOT_CONVERGED`，不将其声称为完全收敛。
