# ADR-004：计算依赖路线（草案，未冻结）

状态：**未完成，待完整同基准 R 对照及统计负责人审核**。当前不能宣称依赖选型已根据施工单所要求的三路线完整基准冻结。

## 可得证据

- 先前 PoC 的公开 GL003 A.1：自研 F=1.167718536979458、Ss=1.8616599522409474；pt13528 0.1.11 的 F=1.1677185369794583、Ss=1.8616599522409485。R 4.3.3 的对应值为 F=1.16771853697946、Ss=1.86165995224094。
- A.2：自研 F=3.7767470624613484、Ss=0.2916125490919051；pt13528 的 F=3.7767470624613484、Ss=0.2916125490919051；R 的 F=3.77674706246136、Ss=0.291612549091906。以上为 `validation/crosscheck_report.json` 和计划阶段 PoC 记录的公开数据，显示尾数差异。
- 合成负方差例：三个路线均将 Ss 截零；R 的 ANOVA 线性模型对理论零组间均方得到约 `1.44e-31`，相对零严格误差为 1，故未通过施工单相对容差。原因是浮点舍入，不能以此消除差异。
- 不平衡例当前仅自研与 R 有对照；pt13528 的该均匀性接口要求矩形数据，不能当作完整覆盖。

## 路线比较（阶段性）

| 路线 | 覆盖及差异 | 许可和安装维护成本 |
|---|---|---|
| openpt 自研 | 覆盖现有均匀性、稳定性、稳健统计、指定值和评分业务接口；扩展设计仍须批准 | Apache-2.0；使用 SciPy 等依赖，需要自行维护公式、验证和安全更新 |
| pt13528 0.1.11 | 上述公开平衡例与自研接近；矩形接口、不支持相同的不平衡输入；与自研共用 SciPy，非完全独立 | LGPL-3.0-or-later；可选 Python 包，维护状态须发布前重新核查，需审查分发义务 |
| R 4.3.3 | base R `aov` 及 `t.test`，另按公式独立实现稳健与评分；目前仅覆盖少数数据，详见阶段性报告 | R 为 GPL 系列，独立外部进程运行；需要单独安装 R 并维护版本，包许可另行核查 |

## 候选方向及未决事项

当前实现保持核心自研、pt13528 可选对照；R 可用于独立对照，但**该配置只是现状，不是基于完整三路线基准形成的新冻结结论**。尚需完成全部公开与内部基准、随机样例、停止规则差异、R 包许可证和上游维护状态核查，再由统计负责人审核并决定是否冻结。
