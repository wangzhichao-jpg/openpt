# ADR-004：v0.1 计算依赖路线

状态：**技术选型冻结**；统计方法与标准适用性仍待统计负责人批准，技术冻结不等于正式使用或发布批准。此决定只约束 v0.1 的软件架构，不将尚未覆盖的模型视为已验证。

## 决定

v0.1 的核心计算继续使用项目自研实现和 SciPy 分布函数；`pt13528==0.1.11` 与 R 4.3.3 / 可选 metRology 仅用于可选交叉核对，不成为 openpt 必需运行依赖。禁止复制或改写 LGPL 库源码冒充 Apache-2.0。不得因某库支持某公式而自动开放未经批准的模型；将来更换路线、版本或停止规则必须重新进行同基准验证和 ADR 审查。

这个决定基于以下比较而非默认自研：pt13528 有已验证能力、同输入绝大多数结果相符，但其 API 未给出项目所需全部中间量和不平衡输入、许可证及集成义务不同，且其与自研实现共用 SciPy；R 的独立分布函数与模型实现可以降低共同依赖风险，但需要单独环境、其线性模型对退化数据的浮点行为必须解释。保留自研业务和边界处理，并把两者放在可选对照轨道，比将任一外部库默认为全部计算真值更符合当前覆盖面和审计需求。

## 同一输入基准与结果

| 数据集及方法 | 实测范围及结论 | 证据 |
|---|---|---|
| GL003 A.1/A.2、负方差：F、Ss、pooled/Welch t、算法 A/S、NIQR 和评分 | 同输入三路线 57 项，56 项按严格相对误差通过；负方差理论零 F 的 R 线性模型留下极小残差，严格相对误差为 1，未通过，不掩盖 | `validation/threeway_report.md`、`.json` |
| GL002 B1 A/B 及原值导出的 S/D、公开合成工作簿和追溯示例 | 三路线 100 项中 76 项通过，12 项 type 6 仅供参考、12 项 pt13528 接口未覆盖；评分基于相同的指定值和不确定度输入，不代表定值预算本身独立验证 | `validation/threeway_examples_report.md`、`.json` |
| 固定种子 200 组随机样例，均匀性、t、算法 A/S、NIQR、四种评分 | 5600 行中 pt13528 3478 项通过、1722 项未覆盖、400 项为 R type 6 参考；pt13528 有符号 t 按绝对值比较，原始符号保留在 JSON。缺口包括单样本 t、ANOVA 中间量及不平衡设计，不能当作通过 | `validation/threeway_random_report.md`、`.json`；输入 `validation/random_anova_input.csv` |
| S13/S20 内部案例 | 同输入的 R 与 pt13528 对照已运行，结果仅留在内部验证目录，不随公开仓库分发；各实验层级模型及其差异仍须授权专家确认 | 内部 `validation/threeway_internal.md`、`.json` |
| 所有观测完全相同 | openpt 和 pt13528 的 F 不可判定；R `aov` 的舍入残差可使 F 有限，R 自身警告拟合近乎完美不可靠。不能把有限 R 数值解释成可判定 | `validation/degenerate_report.md` 与 `validation/crosscheck_report.md` |

R 端随机 ANOVA 的 30 项及固定负方差例的 2 项在理论零值处不满足纯相对误差 `1e-9`：零与浮点残差比较的相对误差为 1。它们在报告中明确标为差异；没有采用绝对容差将其改判为通过。其他需依赖第三位有效数字停止的 A/S 项以对应显示位一末位容差比较并单列迭代次数。`metRology` 默认停止容差和上限不同，结果另列、不冒称同停止规则通过。

## 覆盖、维护与安装成本

| 路线 | 功能及缺口 | 许可证、维护状况与安装成本 |
|---|---|---|
| openpt 自研 | 包含已实现的均稳性、中间量、稳健统计、指定值及评分、状态和追溯接口；不平衡和不确定度扩展仍须批准 | Apache-2.0；Python 及 NumPy/SciPy 等依赖，免 R 环境。项目维护者和漏洞渠道尚待用户提供；需自行维护验证、兼容性和安全更新 |
| pt13528 0.1.11 | 已有平衡均匀性、稳定性、稳健统计和评分等公开接口；本基准的不平衡均匀性、部分 ANOVA 中间量及单样本 t 没有对应接口；与 openpt 共用 SciPy，非完全独立 | LGPL-3.0-or-later；可选 Python 包，分发须审查 LGPL 义务。现有调查在 2026-11-11 记录上游未归档，0.1.11 发布于 2026-10-28、检视提交 `1d4be25`；这不是对后续维护的保证，升级前须重新核查 |
| R 4.3.3，base R + 可选 metRology 0.9-29-2 | `aov`/`anova`、`t.test`、独立公式和 type 6/7 分位数提供独立对照；退化设计必须单独判定。metRology 默认停止规则不同，不直接当成标准真值 | R 为 GPL 系列，metRology 为 GPL (>= 2)；作为外部进程可选安装，镜像及版本见 `validation/README.md`。需额外安装和维护 R 环境，具体再分发方式须另审；固定版本不能保证自动获得安全更新 |

## 后续验证与权限

ISO 13528/GB/T 28043 扩展条款号、实验单位、相关性和方法适用性仍须统计负责人结合正式文本批准；维护状态及 LGPL/GPL 分发边界在公开发布前复核。真实结果是否放行仍由授权人员决定。用户试点、专家签字和原生 Windows 实测均不由本 ADR 代替。
