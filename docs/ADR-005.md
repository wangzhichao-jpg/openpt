# ADR-005：判据标准差与评价标准差的缺省沿用

## 状态

内测试用，正式评价前须由方法负责人审查。

## 决策

`方法配置` 保留兼容的机器字段名 `sigma` 与 `sigma_pt`。模板显示名称分别为“均匀性/稳定性判据标准差”和“z 等评价标准差”。前者用于均匀性和稳定性限值，后者用于 z 等需要能力评价标准差的统计量；二者的物理量、单位及依据必须由用户核实。

如果只填写其中一项，计算器把该值同时用于两个用途；两项均填写时各自使用，不因数值不同而覆盖。都未填时不推算。计算书注明是否自动沿用；原始配置和全精度结果仍分别记录。仅有 `delta_e` 时，不从其推算标准差；GB/T 依据与扩展判据仍遵循原有显式选择规则。

该约定不从稳定性均值差估计不确定度，也不替代指定值表中临时值、最终值及其确定程序的独立登记。一个工作簿仅支持一个被测量，多被测量按后续设计处理。
