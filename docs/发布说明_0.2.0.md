# OpenPT 0.2.0 发布说明（本地准备，未公开发布）

## 新功能

- GB/T 28043 附录 B 均匀性和稳定性模式，支持 δE 基本判据。
- GL003 4.2 和 4.3 的主判据可选，支持 5.3 均值差法。
- 支持宽表和多被测量；破坏性检测可登记相邻试件或单次测量。
- 回归趋势稳定性、传递标准逐点稳定性和 En 不确定度衔接。
- 复核支持声称值内部一致性检查，计算书提供结论摘要及原始数据追溯。

## 验证摘要

已用真实 PT 资料进行 8 轮封闭内测；18 个真实数据集、20 个趋势序列和 6 个校准项目与独立实现一致。R 独立对照已作为 CI 门槛；基线版本的原生 Windows CI 通过。这些验证不等于所有实验设计和标准适用性均已批准。

## 残余风险与未覆盖设计

- 标准条款适用性和扩展方法须由统计负责人批准；Fm（m>2）须经专家复核。
- PT-CX-18 中的回归趋势法限定于特定领域，不能直接推广。
- ISO Guide 35、JJF 1343、JJF 1587 在资料库中没有原文，相关引用待核。
- 尚未开展用户试点；结论须由授权人员签字。
- 软件无法确认数据真实性、样品独立性及未声明的相关性或不确定度重复计入。

## 升级说明

从 0.1.0 升级时重新核对各项目预选方法、判据和适用依据。`run` 和 `review` 默认仅在 `runs/<id>/` 保存计算书、结果 JSON 和复核差异表，不再在输入文件旁生成或覆盖文件；这是不兼容的变化。需要额外输出时分别指定 `--docx`、`--json`、`--differences`；实际路径见命令行输出。
